# Server Stats

A Bash script that analyzes basic Linux server performance statistics.

## Features

- Total CPU usage
- Total memory usage
- Total disk usage
- Top 5 processes by CPU usage
- Top 5 processes by memory usage

## Requirements

- Linux
- Bash
- top
- free
- df
- ps

## Usage

Make the script executable:

```bash
chmod +x server-stats.sh
```

Run the script:

```bash
./server-stats.sh
```

## Example Output

```text
CPU Usage: 12.5%
Memory Usage: 40%
Disk Usage: 55%
...
```
