# DevOps Roadmap Projects

This repository contains hands-on projects completed as part of my DevOps learning journey. The goal is to build practical skills through real-world projects covering Linux, Networking, Bash Scripting, Git, Docker, Kubernetes, CI/CD, Cloud Platforms, Infrastructure as Code, Monitoring, and Site Reliability Engineering (SRE).

Rather than focusing only on theory, each project demonstrates the implementation of DevOps concepts, tools, and best practices.

---

## Learning Objectives

* Develop strong Linux administration skills
* Automate repetitive tasks using Bash scripting
* Master version control with Git and GitHub
* Build and manage containers with Docker
* Orchestrate applications using Kubernetes
* Implement CI/CD pipelines
* Work with cloud platforms such as AWS
* Manage infrastructure using Infrastructure as Code (IaC)
* Configure monitoring and logging solutions
* Apply DevOps best practices to real-world scenarios
