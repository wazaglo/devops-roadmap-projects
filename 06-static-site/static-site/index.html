🚀 DevOps Roadmap Project 06

Static Site Served with Nginx on AWS EC2

About This Project

This static site is deployed using Infrastructure as Code with Terraform on AWS EC2, running Debian 12 with Nginx as the web server.

Deployment is automated using rsync via a simple deploy.sh script.

Technologies Used

☁️ AWS EC2
🏗️ Terraform
🐧 Debian 12
🌐 Nginx
🔑 SSH Keys
📦 rsync

Architecture

Terraform
    │
    ▼
AWS EC2 (Debian 12)
    │
    ├── Security Group
    │     ├── TCP 22 (SSH)
    │     └── TCP 80 (HTTP)
    │
    ├── AWS Key Pair
    │
    ├── User Data (cloud-init)
    │     ├── apt update & install nginx
    │     ├── Configure nginx
    │     └── Start nginx service
    │
    └── Static Site (rsync deploy)
          ├── index.html
          ├── style.css
          └── images/

Deployment

After Terraform provisions the infrastructure, deploy your changes with:

./deploy.sh

This uses rsync to sync the local static-site/ directory to /var/www/html/ on the server.
